# Permanent Portfolio · 恒久投資組合

A personal tracker for the Harry Browne permanent portfolio strategy (equal-weight
stocks / long-term bonds / gold / cash), built with React + Vite + Recharts.

Data is stored in the browser's `localStorage`, with optional cross-device sync
via a private GitHub Gist (configured under Settings → Cloud Sync). JSON
export/import is available as a manual fallback.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
```

Outputs a production build to `dist/`.
